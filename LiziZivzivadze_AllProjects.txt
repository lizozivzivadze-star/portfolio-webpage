-------------------------------------------------------------------------------

PC handling all API calls. Learned I2S audio protocol, PCM/WAV audio format
handling, HTTP streaming, ESP32 heap management, and ffmpeg audio processing.
Used AI for architecture planning, debugging memory fragmentation, and audio
pipeline troubleshooting.
Hardware: ESP32, INMP441 I2S microphone, MAX98357 amplifier, 4ohm speaker,
SSD1306 OLED, DHT11, active buzzer, TP4056, LiPo, perfboard.
