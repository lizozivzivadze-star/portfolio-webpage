Projects

Mini Solar Power Station

URL

Solar power, temperature & humidity on an OLED.

A desktop solar station that shows live voltage, temperature, and humidity on a small screen, so anyone can actually see clean energy working in real time. I built it to turn an abstract idea into something you can watch and understand — and to teach myself how sensors and microcontrollers work together.
The station runs on an ESP32 microcontroller, which reads temperature and humidity from a DHT11 sensor and measures the panel's output through a voltage divider. Everything is displayed live on an OLED screen, powered directly by the solar panel itself.
I learned how to read analog sensor data and scale it correctly with a voltage divider, how to drive an OLED display over I2C, and how to structure clean embedded firmware. It sharpened my skills in embedded programming, real-time data handling, and debugging hardware and code together.
