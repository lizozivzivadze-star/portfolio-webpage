Privacy

Last updated: September 2026

lizibuilds.tech is a static personal portfolio site for Lizi Zivzivadze. It has no user accounts, no server-side database, and no on-site contact form — reaching out happens through the external email, WhatsApp, and LinkedIn links on the homepage and Contact page, not through anything this site itself collects or stores.

What this site does not do

  • No cookies are set by this site's own code.
  • No analytics, advertising, or session-tracking scripts are included.
  • No forms submit data anywhere; there is nothing to fill in and send.

Third-party resources

The site loads web fonts from Google Fonts (fonts.googleapis.com / fonts.gstatic.com) and a CSS framework from the Tailwind CDN (cdn.tailwindcss.com). Like any external resource, requests to those domains may be logged by their respective providers according to their own privacy policies.

Hosting

The site is hosted as a static deployment on Vercel, which — like most web hosts — may keep standard server access logs (such as IP address, user agent, and request timestamp) for operational and security purposes, governed by Vercel's own privacy policy.

Questions

If you have a question about this statement, reach out via the channels on the Contact page.
